# مستندات فارسی CoreLink

این شاخه ترجمهٔ فارسی بخش‌های معماری و عملیاتی مهم مستندات توسعه‌دهندگان CoreLink است. مرجع نهایی رفتار API و schemaها همچنان قراردادهای نسخه‌دار در [`api-contracts`](https://github.com/CoreLinkPlatform/api-contracts) هستند.

## نسخه فعلی

- [مستندات فارسی v1](v1/README.md)
- قرارداد عمومی فعلی: `1.0.0-draft`
- وضعیت محصول: Alpha؛ این مستندات ادعای Stable بودن ایجاد نمی‌کنند.

## سیاست هم‌ترازی

نسخه فارسی باید همان contract revision و همان maturity نسخه انگلیسی متناظر را بیان کند. در صورت اختلاف، ابتدا قرارداد machine-readable و سپس نسخه انگلیسی همان release مبنای رفع اختلاف هستند؛ اختلاف نباید با تغییر مستقل ادعای پشتیبانی در ترجمه حل شود.

راهنماهای کامل‌تر و quickstart اجرایی فعلاً در [شاخه انگلیسی v1](../v1/README.md) نگهداری می‌شوند.
