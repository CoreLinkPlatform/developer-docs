# CoreLink Developer Docs Agent Context

This repository is part of the CoreLink product.

## Canonical context

Read the organization source of truth in `CoreLinkPlatform/product-planning`, especially `AGENTS.md`, `PRODUCT_ARCHITECTURE.md`, `GLOSSARY.md`, `STANDARDS.md`, and `architecture/repository-map.yaml`.

## Repository responsibility

`developer-docs` owns human-facing, versioned developer documentation for supported CoreLink APIs, SDKs, integration flows, examples, and developer onboarding.

## Boundaries

- Do not redefine contracts documented normatively in `api-contracts`.
- Do not publish private roadmap details, customer information, provider credentials, or internal-only operational architecture.
- Use canonical CoreLink terminology consistently.
- Examples must use supported public interfaces rather than implementation shortcuts.
- Version documentation when behavior differs across supported releases.
